# Quota enforcement implementation plan

**Goal:** Per-tenant size caps with automatic read-only flip when exceeded. Adds `set-quota`/`unset-quota` subcommands, a `check-quotas` sweep subcommand, and a cron entry installed by the plugin.

**Architecture:**
- Per-tenant cap stored in `$PLUGIN_DATA_ROOT/<name>/QUOTA_MB`. Absent file → use `$PLUGIN_DEFAULT_QUOTA_MB` (150).
- A flag file `$PLUGIN_DATA_ROOT/<name>/QUOTA_VIOLATED` tracks whether the database is currently in read-only-due-to-quota state. Lets us skip redundant `ALTER DATABASE` calls and emit clean state transitions.
- `check-quotas` walks every tenant, compares `service_size` (bytes) to `quota_mb * 1024 * 1024`, and flips `default_transaction_read_only` on/off as needed. Idempotent.
- Cron: `install` writes `/etc/cron.d/dokku-shared-postgres` running `dokku shared-postgres:check-quotas` every 5 minutes. Operator can disable by removing the file.

**Out of scope:** `tablespace`-based hard caps, alerting/notifications, auto-deletion of old data. Operator-facing problem; we document recovery as "free space or raise the cap".

#### Implementation (append to `functions`):

```bash
service_get_quota_mb() {
  local name="$1"
  local f="$PLUGIN_DATA_ROOT/$name/QUOTA_MB"
  if [[ -s "$f" ]]; then
    cat "$f"
  else
    printf '%s' "$PLUGIN_DEFAULT_QUOTA_MB"
  fi
}

service_set_quota_mb() {
  local name="$1" mb="$2"
  if ! [[ "$mb" =~ ^[1-9][0-9]*$ ]]; then
    echo "quota must be a positive integer (megabytes): $mb" >&2
    return 2
  fi
  service_exists "$name" || { echo "service does not exist: $name" >&2; return 3; }
  printf '%s' "$mb" >"$PLUGIN_DATA_ROOT/$name/QUOTA_MB"
}

service_unset_quota_mb() {
  local name="$1"
  service_exists "$name" || { echo "service does not exist: $name" >&2; return 3; }
  rm -f "$PLUGIN_DATA_ROOT/$name/QUOTA_MB"
}
```

### Q-2: `service_check_quota` (TDD)

**Files:** `functions`, `tests/quota.bats`

`service_check_quota <name>` does one tenant's sweep:
- Read quota_mb (via `service_get_quota_mb`)
- Read size in bytes (via `service_size`)
- If `size > quota_mb * 1024 * 1024`:
  - If no `QUOTA_VIOLATED` marker → `ALTER DATABASE ... SET default_transaction_read_only = on`, write marker, echo `flipped name=<name> -> read_only`
  - Else: nothing (already enforced)
- Else (under cap):
  - If `QUOTA_VIOLATED` marker present → `ALTER DATABASE ... SET default_transaction_read_only = off`, remove marker, echo `released name=<name> -> writable`
  - Else: nothing

#### Implementation (append to `functions`):

```bash
service_check_quota() {
  local name="$1"
  service_exists "$name" || { echo "service does not exist: $name" >&2; return 3; }

  local quota_mb size_bytes cap_bytes
  quota_mb="$(service_get_quota_mb "$name")"
  size_bytes="$(service_size "$name")"
  cap_bytes=$((quota_mb * 1024 * 1024))

  # service_size may emit empty string when psql is unreachable; treat as 0.
  [[ -z "$size_bytes" ]] && size_bytes=0

  local marker="$PLUGIN_DATA_ROOT/$name/QUOTA_VIOLATED"

  if (( size_bytes > cap_bytes )); then
    if [[ ! -f "$marker" ]]; then
      run_psql_admin "ALTER DATABASE \"$name\" SET default_transaction_read_only = on;" >/dev/null
      : >"$marker"
      printf 'flipped name=%s size_bytes=%s cap_bytes=%s -> read_only\n' \
        "$name" "$size_bytes" "$cap_bytes"
    fi
  else
    if [[ -f "$marker" ]]; then
      run_psql_admin "ALTER DATABASE \"$name\" SET default_transaction_read_only = off;" >/dev/null
      rm -f "$marker"
      printf 'released name=%s size_bytes=%s cap_bytes=%s -> writable\n' \
        "$name" "$size_bytes" "$cap_bytes"
    fi
  fi
}
```

#### Append to `install` (after `ensure_shared_container`):

```bash
# Install the periodic quota check. Operators can disable by removing this file.
CRON_FILE="/etc/cron.d/dokku-shared-postgres"
if [[ -w "$(dirname "$CRON_FILE")" || "$(id -u)" -eq 0 ]]; then
  cat >"$CRON_FILE" <<'CRON_EOF'
# Periodic quota enforcement for dokku-shared-postgres tenants.
# Removes when the plugin is uninstalled (clean up manually if needed).
SHELL=/bin/bash
PATH=/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin
*/5 * * * * dokku dokku shared-postgres:check-quotas >/dev/null 2>&1
CRON_EOF
  chmod 0644 "$CRON_FILE" || true
  echo "shared-postgres: installed cron at $CRON_FILE"
else
  echo "shared-postgres: skipped cron install (no write permission to /etc/cron.d)" >&2
fi
```

#### README — add a "Quotas" section after Architecture:

```markdown
## Quotas

Each tenant has a soft size cap (default 150 MB). A cron job runs every 5 minutes and flips
the database to `default_transaction_read_only = on` when the cap is exceeded; the same
job releases the read-only flag once the tenant frees enough space.

```bash
# Raise the cap for a chatty tenant:
dokku shared-postgres:set-quota myapp_db 500

# Clear the override (back to the global default):
dokku shared-postgres:unset-quota myapp_db

# Run the sweep on demand:
dokku shared-postgres:check-quotas
```

The cron entry lives at `/etc/cron.d/dokku-shared-postgres`. Remove that file to disable
automatic enforcement; you can still call `check-quotas` by hand.
```
